# Watermark Offline — Rust + Tauri 2 (Android)

> **الحالة بصراحة:** هذا مشروع مصدر جاهز للبناء، لكن **لم يُبنَ منه APK ولم يُختبر في وضع الطيران**، لأن بيئة الإنشاء حجبت الوصول إلى crates.io وdl.google.com (Android SDK/NDK) وMaven/Gradle وrustup وnpm. لا يوجد APK في هذه الحزمة.

## ما الذي تغيّر عن واجهتك الأصلية
الواجهة (HTML/CSS/JS ومحرك العربية والخطوط المدمجة base64) كما هي. التعديلات فقط:
1. إزالة كل روابط CDN؛ المكتبات تُحمَّل من `src/vendor/` (لا توجد أي طلبات خارجية في الكود).
2. `WMNative` (في `index.html`): يحفظ PDF/JSON عبر نافذة الحفظ الأصلية في أندرويد (`tauri-plugin-dialog` + `tauri-plugin-fs`)، وإن فشلت يجرّب مشاركة النظام، ثم التنزيل العادي (يعمل أيضًا في المتصفح).
3. حفظ الإعدادات والقوالب: `localStorage` كما كان، مع نسخة دائمة في مجلد بيانات التطبيق عبر أوامر Rust (`state_load`/`state_save`) تُستعاد تلقائيًا إن مُسح تخزين WebView.
4. اختيار الملفات (PDF، صورة/PDF العلامة، الخط، استيراد القوالب) يبقى عبر `<input type=file>` الذي يفتح منتقي ملفات أندرويد الرسمي (SAF) داخل WebView.
5. أيقونة التطبيق: `app-icon.png` (أيقونتك: ورقة PDF + ختم WATERMARK) بخلفية كاملة مناسبة للأيقونات التكيفية.

## ما الذي اختُبر فعلًا (في Chromium هنا، بدون Tauri حقيقي)
- تحميل الصفحة مع CSP الصارم بدون أي طلب خارجي، واستيراد PDF من 3 صفحات، وإضافة علامة نصية (لاتيني + عربي)، وإنتاج PDF صالح بـ 3 صفحات (تحققت من الرسم).
- مسار الحفظ الجديد (مع محاكاة `__TAURI__`): استُدعيت نافذة الحفظ ثم الكتابة بالبايتات الصحيحة.
- حفظ قالب باسم، تصديره، واستعادته من نسخة Rust بعد مسح `localStorage` (محاكاة).

## ما **لم** يُختبر
- أي تجميع Rust أو بناء Gradle/APK، أو التشغيل على أندرويد/المحاكي، أو وضع الطيران.
- **PDF.js 3.11.174 لم يكن متاحًا هنا** (الحزمة المحلية المتوفرة 6.2.108 لا تطابق كود الواجهة). لذلك `src/vendor/` يحوي `pdf-lib.min.js` (1.17.1، مضمَّن) فقط، أما `pdf.min.js` و`pdf.worker.min.js` فينسخهما `npm run vendor` تلقائيًا من `pdfjs-dist@3.11.174` (مثبّتة في package.json)، والبناء **يفشل** إن غابا — فلا يمكن إنتاج APK يعتمد على الإنترنت بالخطأ. بدون PDF.js تعمل العلامة والتصدير لكن المعاينة لا تعمل.

## التحقق من الـ crates والإضافات (من وثائق Tauri، ولم يُتحقق منه بالبناء هنا)
| العنصر | أندرويد | ملاحظة |
|---|---|---|
| tauri 2 | نعم | `mobile_entry_point` + `cdylib` موجودان |
| tauri-plugin-dialog 2 | نعم | يدعم المنتقي/الحفظ عبر Intents؛ **يجب اختبار `save` على جهاز حقيقي** |
| tauri-plugin-fs 2 | نعم | يكتب إلى `content://` الناتج من الحوار |
| serde_json | نعم | Rust خالص |
| lopdf (غير مستخدم) | نعم | Rust خالص؛ لم أستخدمه لأن pdf-lib يؤدي المطلوب، وفيه تشكيل العربية وتضمين الخطوط بلا بديل جاهز في Rust، وإعادة كتابته ستخاطر بالوظائف |

**قيد معروف:** إن لم تعمل نافذة الحفظ في إصدارك فالبديل المبرمج هو قائمة المشاركة؛ وإن لم تعمل فالتنزيل العادي (قد لا يعمل داخل WebView أندرويد).

## البناء (يحتاج إنترنت مرة واحدة فقط؛ التطبيق نفسه أوفلاين)
**الأسهل — GitHub Actions:** ارفع المجلد إلى مستودع، شغّل workflow "Build Android debug APK"، ونزّل الـ APK من Artifacts.

**محليًا:** ثبّت Rust وNode 18+ وJDK 17 وAndroid SDK + NDK، عيّن `ANDROID_HOME` و`NDK_HOME`، ثم `./build-android.sh`.
الناتج: `src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk`

## اختبار وضع الطيران
ثبّت الـ APK، فعّل وضع الطيران، افتح التطبيق، ثم: افتح PDF ← تأكد من المعاينة ← علامة نصية وصورة ← تدوير/شفافية/موضع ← نطاق صفحات ← خط مخصص ← احفظ قالبًا ← أغلق التطبيق وأعد فتحه ← صدّر PDF وافتح الناتج.
